# 공개 아카이브 히어로 캐릭터 반응형 크기 개선 계획

## 목표

화면 오른쪽 위의 Hong 캐릭터가 넓은 화면에서 남는 여백에 맞춰 자연스럽게 커지도록 개선한다. 원본이 전신 이미지이므로 캐릭터가 잘리거나 얼굴·하체가 잘리지 않아야 하며, 좁은 화면에서는 제목과 검색 영역을 침범하지 않아야 한다.

## 현재 원인

- `archive-hero-top`의 오른쪽 그리드 열이 데스크톱 `76px`, 모바일 `64px`로 고정되어 있다.
- 캐릭터 이미지도 데스크톱 `76px x 96px`, 모바일 `64px x 80px`로 고정되어 있다.
- 이미지 원본은 세로형 전신 PNG이므로 고정된 작은 상자에 맞추는 현재 방식이 오른쪽 여백을 활용하지 못한다.
- `object-fit: cover`는 이미지 일부를 잘라낼 수 있어 전신 보존 요구와 맞지 않는다.

## 구현 방향

1. 캐릭터 너비를 CSS `clamp()`로 정의한다.
   - 데스크톱: `112px` 이상, 뷰포트에 비례해 증가, 최대 `184px`
   - 모바일: `84px` 이상, 뷰포트에 비례해 증가, 최대 `128px`
2. 그리드의 오른쪽 열과 이미지 너비가 같은 CSS 변수를 공유하게 한다.
3. 이미지 높이는 고정값 대신 `height: auto`로 두어 원본 전신 비율을 보존한다.
4. `object-fit: contain`을 사용해 이미지가 상자 안에서 잘리지 않도록 한다.
5. 기존의 작은 화면 `margin-top` 보정은 유지하되, 크기 증가로 제목과 겹치는지 확인한다.

## 변경 범위

- `src/app/globals.css`
  - 히어로 그리드의 캐릭터 열을 유동 크기로 전환
  - 데스크톱·모바일 캐릭터 크기와 간격 조정
  - 전신 보존을 위한 `height: auto`, `object-fit: contain` 적용
- `src/features/archive/archive-hero.tsx`
  - Next Image의 intrinsic width/height를 원본 비율을 설명하는 값으로 정리
  - 반응형 표시 크기는 CSS가 담당하도록 `sizes`를 갱신
- `src/features/archive/archive-hero.test.tsx`
  - 캐릭터가 제목 옆 히어로 영역에 남아 있는지 확인
  - 전신 보존을 위한 이미지 속성 계약을 회귀 테스트로 고정

## 검증 기준

- 데스크톱에서 오른쪽 빈 공간이 줄고 캐릭터가 현재보다 크게 보인다.
- 모바일에서 캐릭터 전체가 보이고 제목, 검색창, 태그 영역과 겹치지 않는다.
- 캐릭터 이미지가 `/_next/image`로 변환되지 않고 기존 정적 자산 경로를 사용한다.
- `npm test -- src/features/archive/archive-hero.test.tsx`가 통과한다.
- `npm run lint`와 `npm run build`가 통과한다.

## 위험과 대응

- PNG 내부에 투명 또는 배경 여백이 있으면 CSS 크기 확대만으로 시각적 캐릭터가 충분히 커지지 않을 수 있다. 먼저 전신 보존 CSS를 적용하고, 잔여 내부 여백이 확인될 때만 원본을 훼손하지 않는 별도 크롭 자산을 검토한다.
- `transform: scale()`은 레이아웃 공간을 늘리지 않아 제목과 겹칠 수 있으므로 사용하지 않는다.
