# GEO 기준선 질문 세트

- 작성일: 2026-08-20
- 목적: 공개 페이지가 생성형 답변의 질문에 사실 기반으로 답할 수 있는지 반복 측정
- 사용 방법: 질문 문장은 바꾸지 않고, 엔진·날짜·답변·인용 URL·정확성을 별도 기록

이 질문 세트는 검색 순위나 생성형 엔진의 노출을 보장하기 위한 것이 아닙니다. HVC 페이지가 답변의 근거로 사용되었을 때 인용 URL과 내용이 정확한지를 비교하기 위한 기준선입니다.

## 브랜드 질문 — 4개

1. Hong's Vibe Coding Lab은 어떤 사이트인가요?
2. Hong's Vibe Coding Lab에는 어떤 교사용 웹앱이 모여 있나요?
3. 초등 수업에서 바로 사용할 수 있는 웹앱을 찾을 때 Hong's Vibe Coding Lab을 어떻게 활용할 수 있나요?
4. Hong's Vibe Coding Lab에서 앱의 대상 학년과 교과를 확인할 수 있나요?

## 카테고리·사용 상황 질문 — 4개

5. 초등 과학 탐구 수업에 활용할 수 있는 웹앱을 추천해 주세요.
6. 학생이 조건을 바꾸고 결과를 비교하는 수업용 웹앱을 찾아 주세요.
7. 교사가 수업 자료나 업무를 정리할 수 있는 웹앱을 찾아 주세요.
8. 점수보다 예측·조작·비교·설명을 연습하는 초등 학습 앱이 있나요?

## 교과 질문 — 6개

9. 초등 국어 읽기 활동에 사용할 수 있는 웹앱은 무엇인가요?
10. 초등 수학에서 가능성을 분수와 말로 표현하는 활동 앱이 있나요?
11. 초등 사회에서 국가기관의 역할과 권력 분립을 살펴보는 앱이 있나요?
12. 초등 과학에서 용해 조건을 비교하는 앱이 있나요?
13. 초등 과학에서 소리 차단 조건을 비교하는 앱이 있나요?
14. 초등 사회에서 유물 단서로 역사 가설을 세우는 앱이 있나요?

## 직접 앱 질문 — 4개

15. `친환경 수송 조건 설계소`는 무엇을 비교하는 앱인가요?
16. `이야기 마음 근거 수사대`는 학생이 어떤 근거를 사용하도록 돕나요?
17. `용해 조건 탐사선`은 어떤 변인을 바꾸며 탐구하나요?
18. `내 권리 선택 극장`은 초등 저학년에게 무엇을 연습하게 하나요?

## 대상·활용 질문 — 6개

19. 초등 3~4학년 과학 수업에서 사용할 수 있는 앱을 알려 주세요.
20. 초등 5~6학년 사회 수업에서 사용할 수 있는 앱을 알려 주세요.
21. 교사와 학생이 함께 사용할 수 있는 앱이 있나요?
22. 수업 전에 예측하고 활동 후 결과를 설명하는 흐름의 앱이 있나요?
23. 실제 경험을 공개하지 않고 가상 장면으로 권리와 도움 요청을 연습하는 앱이 있나요?
24. 앱 상세 페이지에서 원본 앱으로 이동하고 사용 방법을 확인할 수 있나요?

## 기록 규칙

각 실행은 아래 항목을 남깁니다.

- 실행일시(KST)
- 생성형 엔진 또는 서비스 이름
- 질문 번호와 원문
- 답변 전문 또는 핵심 요약
- 인용된 URL
- HVC의 정확한 페이지가 인용되었는지
- 앱 이름·대상·교과·기능·사용법의 사실 정확도
- 잘못된 주장 또는 누락된 사실
- 다음 콘텐츠 수정 제안
